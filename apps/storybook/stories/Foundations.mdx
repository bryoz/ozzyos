# OzzyOS

Tokens live in `tokens/` (W3C DTCG JSON) and build with Style Dictionary into CSS variables, JS and JSON.

Use the **Brand** and **Mode** toolbar buttons to preview every brand × light/dark combination.

| Layer | Package | Use |
|---|---|---|
| Tokens | `@ozzyos/tokens` | CSS variables, JS constants, JSON |
| Foundation CSS | `@ozzyos/css` | reset, typography, `.oz-prose`, layout, component styles (`.oz-button`) |
| Components | `@ozzyos/react` | React components on React Aria, styled by `@ozzyos/css` |
