# OzzyOS

Tokens live in `tokens/` (W3C DTCG JSON) and build with Style Dictionary into CSS variables,
JS, JSON and a WordPress `theme.json` per brand.

Use the **Brand** and **Mode** toolbar buttons to preview every brand × light/dark combination.

| Layer | Package | Use |
|---|---|---|
| Tokens | `@ozzyos/tokens` | CSS variables, JS constants, `theme.json` |
| Foundation CSS | `@ozzyos/css` | reset, typography, `.oz-prose`, layout, `.oz-button` |
| Components | `@ozzyos/components` | Lit web components (`<oz-button>` …) |
